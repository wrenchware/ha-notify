# Changelog

## 0.1.0

- Native Windows notifications from Home Assistant's Mobile App integration.
- WinUI 3 settings window with automatic Windows theme matching.
- Background tray operation and optional startup at sign-in.
- Automatic reconnection through Home Assistant restarts.
- Windows-encrypted credentials stored outside the app directory.
- Official Home Assistant logo and Home Assistant notification header; app named HA Notify.
- Title and message support, with separate connection and notification test status.
